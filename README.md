# HG Astro Extras

These are some common [Astro](https://astro.build/) components used across [Half-Gray](https://www.halfgray.xyz/)'s websites.

These components may be incorporated into [Grayspace](https://github.com/jack126guy/grayspace) in the future, although Grayspace is not required to use them.

## Requirements

* Astro 4 or 5
